# Admin Manual

## Admin Role

The administrator is responsible for keeping the civic learning space accurate, respectful, and safe for community participation.

## Dashboard

The dashboard shows counts for users, artwork, pending submissions, and open reports. It also highlights active civic categories and the newest platform activity.

## Moderate Artwork

Approve or reject uploads from the artwork management page. Approve work that is educational, accurate, and respectful. Reject work that contains misinformation, hate speech, or offensive imagery.

## Moderate Comments

Hide or unhide comments from the comments page.

## Manage Users

Change user roles between `user` and `admin`.

## Manage Categories

Add or edit civic education categories such as voting, democracy, leadership, anti-corruption, and youth participation.

## Review Reports

Update report status after checking the reported artwork and take further moderation action if necessary.
